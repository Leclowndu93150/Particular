# Particular Reforged 26.1

## Compatibility

- Targets Minecraft **26.1**, **26.1.1**, and **26.1.2** with a single jar per loader.
- Fabric and NeoForge.

## Dependencies

- **Fabric**: requires Fabric API, Forge Config API Port (26.1.4), and BaguetteLib (≥ 2.0.1). ModMenu is recommended for opening the config screen but not required.
- **NeoForge**: requires BaguetteLib (≥ 2.0.1).

## Tooling

- Build system: Prism Gradle plugin, single branch produces both Fabric and NeoForge jars.
- Java 25.
